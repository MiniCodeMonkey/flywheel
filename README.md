# flywheel

A local CLI that lets Claude build **MOWL / Intelligent Cycling** spinning
courses from Spotify playlists — LLM-driven, playlist-first. Ships with a
Claude **skill** that teaches an agent the whole ride-building workflow, and
works with an optional Spotify MCP for playlist authoring.

Status: **design phase.** See
[`docs/superpowers/specs/2026-08-18-flywheel-design.md`](docs/superpowers/specs/2026-08-18-flywheel-design.md).

Built in public.
